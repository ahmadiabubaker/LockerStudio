📊 Team Performance Dashboard

This dashboard was created using Google Looker Studio to track the performance of a 300-person team over a 2-month event. It features key metrics designed to evaluate engagement, attendance, and task efficiency across the entire team.

🔍 Overview of Metrics

  • 📅 Duration: 2 months
  • 👥 Team Size: 300 members
  • 📈 Metrics: Task completion rates, attendance, engagement trends, performance tiers
  • 🔧 Tools: Google Sheets, Looker Studio, Google Apps Script

📺 Live Dashboard

This project demonstrates how data from large teams can be effectively visualized and used for decision-making in fast-paced event settings.
